# Inspirations concurrents (banque d'écrans)

Screenshots d'écrans d'apps concurrentes, fournis par Jeremy, à réutiliser comme références dans les audits (galerie "comment font les concurrents"). Classés par type d'écran. Source : Mobbin.

Quand un audit touche un de ces types d'écran, intégrer les images correspondantes en galerie dans la section concernée du rapport ET dans la "Proposition d'onboarding".
